AgentViz Very Short Speaking Notes
==================================

Slide 1: Architecture
---------------------

- CLI question -> guard -> ACL -> schema -> Analysis Agent -> SQL validation/execution -> artifact -> Visualization Agent -> chart validation/rendering.
- Stack: Typer CLI, YAML config, Pydantic models, SQLAlchemy/SQLite, sqlglot, OpenAI SDK, Matplotlib.
- Core point: LLMs plan; deterministic code controls security and execution.

Slide 2: LLM Agents
-------------------

- Analysis Agent returns query, clarification, or unsupported.
- Visualization Agent returns ChartSpec.
- Both use structured outputs validated with Pydantic.
- No Pydantic AI: explicit small boundaries are simpler and safer here.

Slide 3: Design Decisions I
---------------------------

- Reject unsafe prompts early.
- Authorize before schema access.
- Validate SQL after LLM proposal.
- Validate ChartSpec before rendering.

Slide 4: Design Decisions II
----------------------------

- Structured outputs, not free text.
- Clarification before guessing.
- Row-free visualization context.
- Optional --save-llm-io for debugging.

Slide 5: Future Improvements
----------------------------

- Real auth and richer authorization.
- Configured relationship catalog for missing foreign keys.
- Large-schema retrieval before LLM planning.

Closing
-------

- This is not "LLM directly queries a database".
- It is semantic LLM planning inside deterministic security boundaries.
