## Learning / supervision workflow

This project is being developed interactively.

Do not implement future milestones unless explicitly requested.

For each milestone:

1. Explain the problem the milestone solves.
2. Explain the relevant concepts and design alternatives.
3. Recommend an approach and justify it.
4. Describe which files/classes/interfaces you propose to create or modify.
5. STOP and wait for approval before implementation when explicitly asked
   to work in planning mode.

During implementation:
- Make small, reviewable changes.
- Avoid unrelated refactoring.
- Explain non-obvious code and design decisions.
- After implementation, summarize the execution flow through the new code.
- Show how to manually test the feature.
- Run automated tests and report results.
- Point out weaknesses, edge cases, and alternatives.
